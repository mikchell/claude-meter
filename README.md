# claude-meter

Claude Code の入力欄の上に、使用量を2行でさっと見せるバーです。

```
5h ♥ ██████████░░░░░░░░░░             52%  ↻14:30 │ Session 12.3k tok ✻
7d ♥ ████░░░░░░░░░░░░░░░░             21%  ↻10/14
```

## 表示内容

| 項目 | 内容 |
|---|---|
| 5h | 5時間ごとの利用枠の使用率と、リセット時刻(↻) |
| 7d | 週ごとの利用枠の使用率と、リセット日(↻) |
| Session | このセッションで使ったトークン量(入力+出力+キャッシュ書き込み) |
| バー | 20マスで、1マス = 5%。埋まった分が使用率です。色はClaudeのオレンジで、残りが10%を切ると赤になります。空きの部分は薄いグレーです |
| アイコン | 残り10%ごとの10段階で ♥ → ♡ → ▲ → ! → ☠ と変わり、アイコンの色が緑から赤へ変わります |

- 作業中は右の ✻ が回り、ターンが終わると少しの間 ♥ になります。
- 5h・7d はサブスクリプション(Pro / Max など)の利用者向けです。API キーで使っている場合は「—」と表示されます。
- 外部には何も送信しません。Claude Code 自身が持っている使用量の情報を表示するだけです。

## インストール

Claude Code のプロンプトで、次の1行を実行します。

```
/plugin install claude-meter --marketplace mikchell/claude-meter
```

「マーケットプレイスを追加しますか?」と聞かれたら `y`、次にスコープ(`user` がおすすめ)を選びます。以降、新しく開いたセッションから表示されます。

## アンインストール(削除)

プラグインを外す場合は、次のコマンドを実行します。

```
/plugin uninstall claude-meter
```

ターミナルから実行する場合は、次のとおりです。

```bash
claude plugin uninstall claude-meter
```

追加したマーケットプレイスも消したい場合は、続けて次を実行します。

```bash
claude plugin marketplace remove claude-meter
```

削除したあとは、新しく開いたセッションから、バーが表示されなくなります。

## 調整

`hooks/register.tsx` の先頭付近の定数で、見た目を変えられます。

- `BAR` — バーの長さ(既定 20、1マス = 5%)
- `TIER_COLORS` / `TIER_GLYPHS` — 残り10%ごとの10段階の色と記号
